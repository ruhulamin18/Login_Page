# ⬡ Nexus — React Login Page

A clean, modern login page built with **React.js**, **Vite**, and **pure CSS**. Features a split-screen dark UI, animated rotating motivational messages, and smooth form interactions.

---

## ✨ Features

- 🌗 Split-screen layout — branded left panel + login form right panel
- 💬 Rotating motivational message banner (auto-changes every 4 seconds with fade animation)
- 👁️ Show / hide password toggle
- ⚡ Loading spinner on form submit
- ✅ Basic form validation with inline error message
- 🔵 "Continue with Google" button
- 📱 Fully responsive — mobile friendly
- 🎨 Dark theme with indigo / violet accent palette

---

## 🛠️ Tech Stack

| Tool | Purpose |
|------|---------|
| React 18 | UI components & state |
| Vite 5 | Dev server & bundler |
| Pure CSS | Styling (no UI library) |

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) v18 or higher
- npm (comes with Node.js)

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/your-username/nexus-login-page.git

# 2. Go into the project folder
cd nexus-login-page

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```

Then open your browser and go to:

```
http://localhost:5173
```

### Build for Production

```bash
npm run build
```

Output will be in the `/dist` folder.
